## 核对事实与近似部分

- **PS5**：原版主板的 8 颗 2 GB GDDR6、6 颗 NAND（两面各 3 颗）分别建为可选组件；风扇采用 120 mm / 45 mm 级包络。叶片数存在供应商差异，当前曲率与 23 片表示一种视觉近似，不作为所有 PS5 的统一风扇规格。CPU 裸芯片面朝向散热组件；没有误加桌面 CPU 金属顶盖。
- **手机**：按照 Apple 官方背部内部视图，底部扬声器在左、Taptic Engine 在右，TrueDepth 与后置双摄分开。标准版不添加 Pro 的第三颗相机。保留 147.6 × 71.6 × 7.8 mm 官方外形参考。
- **相机**：使用 ILCE-7M4 的装配分区，不将 A7R IV / A7R V 拆解冒称为 A7 IV。芯片微观布局、排线弯曲半径与光学处方没有公开测绘，本模型不填入未经核对的具体芯片料号。
- **手柄**：两个自适应扳机与两个线性执行器分别展示；不将触觉执行器当作传统偏心马达。不同 DualSense 硬件修订的电路和机构可能不同。
- **耳机**：从通用原理样机改为 USB-C 版主要组件参考，但仍不声称复制 AirPods 的声学腔体公差、SiP 内部封装或胶粘工艺。独立动圈子层级继续讲解通用原理。

外形曲面、板孔、元件尺寸、微型无源器件位置、排线轨迹和紧固件数量属于观察资料后的几何近似。可视螺钉是代表性采样；电路表面的装饰走线不是真实电气网络。这些模型不能替代维修手册或完整物料清单。

## 实现与计数

- `lib/digital/catalogue.ts` 保留原有 14 个层级与部件 ID。
- `lib/digital/refinements.ts` 维护本轮修正的位置、尺寸、来源与新增组件；已有课程记录和分享链接继续有效。
- `lib/digital/geometry.ts` 实现原生毫米几何：镂空轮廓、薄壁壳体、曲面侧盖、双面封装、微型插座、柔性线路、齿轮及声学部件。
- `lib/digital/models.ts` 负责父子单位换算与安装朝向；变换保存在内层，避免动画重置缩放后子模型变大。
- 新增 42 条部件资料。五类数码设备共有 148 条目录资料，其中 143 个为各层级的可选组件定义，5 个为设备根条目。整个应用为 741 条资料、82 层级、8 台参考设备、24 个实验。
- 支持件和微型无源器件随其总成选中；没有给装饰电路赋予虚构的料号。

## 验证方式

```bash
npm run lint
npm test
npm run build
npm run size
npm start
# 另开终端
node --experimental-strip-types scripts/digital-smoke.mjs
```

几何检查包括父子实际比例、动画前后变换、PS5 内部组件装配间隔与风扇包络、双面封装数量、手机的关键位置与背盖下排线、耳机与盒盖间隙。非凸主板按各实际子组件检查装配区域，避免用整个主板的包围盒填满风扇避让空间。

浏览器验收覆盖 14 层级 × 3 姿态、5 条新增课程、选择/隐藏/恢复、父子深入、中文说明、分类和移动端。截图与验收不是公差测绘、物理声学仿真或全部芯片的逐一鉴定。

## 曲面与板面深化（2026-10-19）

- 新增 molded-shells.ts：手柄前后薄壁壳体、贯通开孔、相机握把内腔、耳机声学头与短柄、圆角充电盒。隐式曲面提取为静态网格；手柄黑色面板单独三角化并贴合表面，避免薄层采样缺面。曲面法线按原始场计算，避免逐三角形反射条纹。
- 新增 board-detail.ts：板面图样按原生毫米归一化，沿异形轮廓裁切；双面支持器件通过实例绘制，避开主要封装和开孔。支持件跟随所属 PCB 选择、拆解与释放资源。
- 芯片外观区分基板、塑封、定位点和底部焊点；焊点阵列只表达封装结构，不宣称球数、引脚分配或真实网络。
- PS5 外盖调整外翻与前后收束，补充进气栅格及底座；相机增加封闭侧壁、控制拨轮和可透视的镜片表面；手机保持 Apple 内部视图朝向并收紧开盖距离。
- 不新增虚构芯片型号或微型器件目录 ID，课程与分享链接保持有效。密集支持件仍是示意布局；这些细节不改变上述精度边界。

## 授权模型与处方数据更新（2026-10-19）

本轮采用 Taohid Animation 的 CC BY 4.0 手柄外观网格，以及 Optiland 的 MIT DoubleGauss 光学处方。此前“全部新增几何独立编写”的描述不再适用于手柄外观与镜片数据。详见 [第三方资源清单](../THIRD_PARTY_ASSETS.md) 与 [资源审核](OPEN-MODEL-AUDIT.md)。

手柄保留 81 个曲面网格、原始 UV 与贴图，重新归入交互总成；内部机构仍由项目根据资料构建，不能由外观模型反推为实测内部尺寸。每次实例独立持有几何、材质和纹理句柄。

镜头为 100 mm、F/5、六片四组教学设计。球面曲率、厚度、胶合关系和轴向间距来自处方；口径与机械结构由项目设计，不是 Sony 商用镜头原厂 CAD。近轴焦距约 100.004 mm，后焦距约 61.488 mm。新增镜片座、压圈、对焦螺旋副、光圈驱动和卡口等，可选部件由 7 增至 20。四分之一剖开镜筒用于观察。

相机有效感光面校正为 36×24 mm，镜头处方像平面与装机后的感光面重合，卡口配合面位于感光面前 18 mm。近轴与装配坐标检查不代表完整像差分析或制造公差验证。

## 五类设备装配深化（2026-10-19，当前）

新增九个探索层级，合计 91 层级、808 条资料、210 个数码组件定义。手机显示、PS5 电源与光驱、相机主板与快门、左右手柄反馈机构、耳柄电路和充电盒管理板均使用独立总成；整机内安装的就是同一份子层级几何。原有分享部件 ID 保留。

手机显示总成总厚度约 0.97 mm，正面朝外，背面柔性连接留在包络内；板上主要封装与屏蔽罩分层。耳机电池与动圈组件沿声腔深度分开，左右耳复用相同总成并转动入盒，耳柄避开电芯，上部声腔盖与下壳采用互补曲面。相机快门向光轴前方先行、导热板向前退出，避免与传感器和主板相向穿插。

Sony 官方 ILCE-7M4 规格列出感光面 **35.9 × 23.9 mm**，本轮用这一数值替代上轮的 36 × 24 mm 名义全画幅值；像平面位置与 18 mm 法兰距保持原装配关系。资料：[Sony 规格](https://www.sony.com/electronics/support/e-mount-body-ilce-7-series/ilce-7m4/specifications)。手机主要装配参考 [Apple 内部视图](https://support.apple.com/en-us/104901)，PS5 参考 [Sony 官方拆解](https://blog.playstation.com/2020/10/07/ps5-teardown-an-inside-look-at-our-most-transformative-console-yet/)，手柄参考 [iFixit 主板拆解](https://www.ifixit.com/Guide/DualSense+Motherboard+Replacement/142487)，耳机参考 [52audio 实机拆解](https://www.52audio.com/archives/178135.html)。

新增机构的微小尺寸、线圈匝数、叶片数及机械支承仍为教学重建，不表示从厂商取得完整 CAD。电源内部功能分区和线性反馈分层是解释性机械设计；照片没有证实的器件料号、绕组参数与电气网络没有虚构。
