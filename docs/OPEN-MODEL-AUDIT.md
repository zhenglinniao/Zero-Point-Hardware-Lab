# 开源模型与数据审核

核对日期：2026-10-19。公开可查看不等于允许再分发；只有许可明确、用途匹配的资源才进入运行资源目录。

| 资源 | 判断与用途 |
| --- | --- |
| [Taohid Animation — PS5 Controller](https://sketchfab.com/3d-models/ps5-controller-b7bb9c5102a04cb0b1966c6d02bad7d6) | 作者平台 API 确认 CC BY 4.0、允许下载。采用外观网格，保留署名和贴图；内部机构另建，不能把外观网格称为内部实测数据。 |
| [Optiland DoubleGauss](https://github.com/optiland/optiland/blob/master/optiland/samples/objectives.py) | MIT。采用曲率、厚度、玻璃序列、光阑位置与后焦距，重建六片四组光学实体。机械结构与有效口径由项目设计。 |
| [refractiveindex.info database](https://github.com/polyanskiy/refractiveindex.info-database) | CC0。采用 Optiland 0.6.3 随附的 SCHOTT 玻璃 Sellmeier 系数，计算折射率。 |
| [PINE64 PinePhone 资料](https://pine64.org/documentation/PinePhone/_full/) | 可用于研究开放硬件装配；尚未核实具体 STEP 文件的再分发许可，未打包进应用，也不能代替 iPhone 15。 |
| [rtql8d PS5](https://sketchfab.com/3d-models/ps5-d788de3735964151a3e24fd59c0f1956) | 页面明确为简化外观模型，无法解决当前内部拆解精度问题，未采用。 |
| [CadCrowd AirPods](https://www.cadcrowd.com/3d-models/airpods-1) | 代际与当前 AirPods Pro 2 USB-C 不符，未采用。 |
| [CadCrowd iPhone 15 Pro Max](https://www.cadcrowd.com/3d-models/i-phone-15-pro-max) | 与项目标准版 iPhone 15 不同，不能混用，未采用。 |

手柄原始文件通过带署名的 [dualsense-studio 镜像](https://github.com/SafaElmali/dualsense-studio/blob/main/controller/ATTRIBUTION.md)获取。文件校验、完整许可与修改范围见 [第三方资源清单](../THIRD_PARTY_ASSETS.md)。未使用公开 CT 查看器内容作为可再分发数据。
